# 酷词岛 KuCiDao

为 OriginOS「岛」加上酷狗逐字歌词的 LSPosed 模块。当前版本 v1.4.6.3。

## 功能

- 逐字歌词，颜色随专辑封面取色
- 歌词样式 7 套，换行过渡 5 种
- 双行预览：主行下方提前显示下一句
- 前奏 / 间奏声波动画 + 倒计时流光
- 外圈光晕（环绕光效），亮度五档可调
- 横屏三选一：默认岛 / 摘岛 / 歌词悬浮窗

## 使用要求

- vivo / iQOO 手机（OriginOS），已 root 并装有 LSPosed
- 酷狗音乐 20.9.0
- 在 LSPosed 中启用本模块，作用域为「系统界面插件」（com.vivo.systemuiplugin），启用后重启相关进程或软重启手机

其他播放器（网易云、落雪等）经通用 MediaSession 通道可显示单行歌词；双行预览与逐字效果依赖酷狗歌词时间轴，为酷狗专属。

## 构建

用 Android Studio 打开本仓库即可构建；也可以推送到自己的 GitHub 仓库，用仓库自带的 Actions 工作流云编译。

注意：正式发布包的签名私钥不公开。本仓库构建出的包使用你自己的调试签名，与正式包签名不同，**不能互相覆盖安装**，切换时请先卸载再安装。
